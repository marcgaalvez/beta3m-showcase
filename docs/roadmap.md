# 🗺️ Roadmap

[← Volver al README](../README.md)

## ✅ Hecho

- [x] Motor de escritura propio con Pointer Events (lápiz, pluma, subrayador, goma, regla)
- [x] Palm rejection y desplazamiento con dos dedos
- [x] Reconocimiento de figuras en local (círculo, rectángulo, triángulo, línea)
- [x] Lazo de selección y objetos flotantes (mover, redimensionar, rotar)
- [x] Escritura a mano → texto y fórmulas manuscritas → LaTeX (KaTeX)
- [x] OCR de fotos: texto, fórmulas y tablas
- [x] Editor enriquecido (Tiptap): tablas, código, fórmulas, comandos `/`
- [x] IA: mejorar, resumir, chat con la nota, preguntas de repaso, flashcards, traducir, explicar, resolver
- [x] Asignaturas con color y emoji
- [x] Offline-first con IndexedDB y cola de sincronización
- [x] Búsqueda full-text (PostgreSQL GIN) con alternativa offline
- [x] Historial de versiones y papelera
- [x] Exportación a PDF y Markdown
- [x] Modo claro y oscuro
- [x] Verificación de email y recuperación de contraseña
- [x] Modo invitado con migración de notas al crear cuenta

## 🚧 En curso

- [ ] PWA instalable (manifest y service worker)
- [ ] Fondos de página (rayas, cuadrícula, puntos)
- [ ] Rendimiento con miles de trazos: índice espacial y simplificación RDP
- [ ] `getPredictedEvents()` para reducir aún más la latencia percibida
